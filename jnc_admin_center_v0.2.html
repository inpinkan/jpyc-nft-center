Admin Centerからチェーン・決済トークン・Marketplace登録を一元管理します。

決済トークン登録

オンチェーン登録を確認してからJNC設定を保存します。

管理キーはVercel環境変数 JNC_ADMIN_KEY と同じ値を入力します。ブラウザには保存しません。Marketplaceへの書き込み操作は運営Fee WalletのMetaMask承認が必要です。読み取り確認ではWallet接続を要求しません。複数Wallet拡張がある環境でもMetaMask Providerを明示選択します。
v1.1.7の登録経路： 入力 → ERC20 decimals取得 → 対象チェーンのMarketplace確認 → 書き込み時だけFee Wallet確認 → Marketplaceへ登録・有効維持 → オンチェーン確認 → ロゴ保存 → KV保存 → JNCへ反映。終了／再開はJNCの新規Shop / NFT受付だけを切り替え、Marketplace Payment Tokenは有効のまま維持します。

ERC20の decimals() から取得します。

運営でも下回れない下限。新規登録後は変更不可です。

ユーザーのList / Offer / Auction開始価格はこの値以上。登録後もAdmin Centerから変更できます。

新規登録時は必須。編集時に未選択なら現在の画像を維持します。
