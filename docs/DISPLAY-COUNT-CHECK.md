# ショップ表示数と発行数の照合（2026-11-01）

本番の公開読込みAPI `/api/load-state?walletAddress=PNC_GLOBAL_MARKET` の34件を、チェーンとNFTコントラクトとToken IDの組で照合した。GETのみで書込みは行っていない。

- 共有表示データ34件の内訳はPolygon33件、BNB1件。
- Polygonの発行履歴38件との差は5件。Token IDは2、3、5、7、8。
- 該当5件はPolygon上のownerOfが現在も成功し、発行先と同じウォレットが所有。tokenURIも取得できた。burnによる不存在ではない。
- 5件は共有表示データにも、確認した発行者ウォレットの保存データにもない。
- 現在の画面は共有保存データからNFTを構成し、チェーン上の全発行NFTを自動列挙しないため、これら5件はショップ表示に現れない。
- 保存データから除かれた理由や時期は現状のデータだけでは確定できない。意図した非公開や試作品の可能性を断定せず、公開への自動復元は行わない。

根拠はローカルartifactsのlive-global-state.jsonとdisplay-discrepancy.json。38件全てのCreator登録が現在の公開33件の切替に必須という説明は修正する。表示しない5件の登録は保留し、今後の運営方針に従う。既存の移行台帳は発行履歴38件のため、公開対象に絞る場合は変更を明示してから行う。すでに登録済みのNFT #1は共有表示データに含まれる。
