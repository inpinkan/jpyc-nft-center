# 旧出品の切替計画

旧出品用の読込み・取消し候補入力をmarketplace-toolsへ追加。公開台帳 `migration/polygon-listings.json` に25記録の元の売主・価格・トークン・NFT・listing IDを記録。接続ウォレット本人と選択した旧市場で絞り、現行listingの各値が一致するものだけ候補にする。終了済みや内容変更は自動選択しない。読込み・入力時には送信しない。市場切替で候補を破棄。画面テスト18項目成功。実際の取消しは切替直前まで保留。

最終画面確認で、保存済みNFT状態に市場アドレスを保持し、参照市場が違う／不明の場合は旧listing ID・offer ID・auction IDを破棄して再照会する処理を追加。Creatorの登録状態も新市場で再読する。旧取引番号で新市場の別取引を操作しないための対応。画面テスト16項目成功。共有保存データの書換えや公開はまだ実施していない。

Polygonの旧出品は23枚分。現行旧市場23記録と、それ以前の市場に残る重複2記録の合計25記録を区別する。価格・決済トークン・売主・Token ID・旧listing IDを `artifacts/listing-migration-plan.json` に保持した。再出品はNFTごとに1件であり、重複した旧記録を2件の再出品にしない。

現在の内訳は、売主…88E9が2枚、…bbc0が4枚、…4047が3枚、…2B6a0が14枚。全ウォレットを運営本人が所有していると確認。…2B6a0はMetaMaskで非表示だったものが見つかった。Creator38枚の登録は完了済み。

## 切替順序

1. BNBの新市場配置、トークン設定とCreator移行を準備する。Polygonの旧出品は維持する。
2. GitHub更新候補と配備先の動作・ファイル一式・API設定を確認し、切替可能な状態を整える。
3. 切替直前に旧市場の出品・オファー・オークション・価格を再取得する。購入済みNFTを旧台帳だけで再出品しない。
4. 売主ウォレットごとに旧出品を取消す。共有表示のキャッシュ更新も確認する。必要に応じ旧市場への承認取消しも本人が行う。取消しから再出品までは販売できない時間があることを運営へ説明する。
5. 新市場の受付と公開画面の切替を整合させ、売主が新市場へ承認・再出品する。所有者・Creator・価格・分配・受取りの案内を再確認する。

本書は実行計画であり、旧出品取消し・旧市場停止・新市場受付開始・本番配備は未実施。旧契約のトークン無効化では既存購入まで停止しない。feeWalletから他ウォレットの出品を取消せるとは扱わない。
